# Semana 03 – Desenvolvimento de Aplicativos React com IA
FlyRank – Engenharia de IA Frontend

Este projeto foi desenvolvido como parte da designação da Semana 3: “Desenvolvimento de Aplicativos React com IA”.  
A aplicação implementa uma busca de filmes usando a API OMDB, seguindo o padrão MVVM e utilizando IA como assistente de desenvolvimento.

## Funcionalidades
- Busca de filmes por título
- Integração com OMDB API
- Estrutura MVVM (Model, View, ViewModel)
- Componentização com React + TypeScript
- Header com campo de busca
- HomeView exibindo resultados em cards

## Tecnologias
- React
- TypeScript
- OMDB API
- IA como copiloto técnico
